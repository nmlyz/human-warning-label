human-warning-label is a tiny program that writes one safety warning label for human beings to a file: a single line, in the wording of a printed label, that warns about something people do every day. The line is 100 characters long, inside the 160-character limit for a printed label.

## The label

> SIDE EFFECTS MAY INCLUDE: Saying 'let me know if you need anything' and quietly hoping you never do.

## Run it

```sh
python3 main.py
```

It writes the label to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run.
